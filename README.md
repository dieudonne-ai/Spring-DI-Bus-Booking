# Spring-DI-Bus-Booking

Spring Framework Dependency Injection demo (BIT2115 - Applied OOP): a Kampala bus ticket booking system.

Shows @Configuration, @ComponentScan, @Component, @Service, @Repository, @Bean, @Primary, @Qualifier,
@Autowired (constructor, setter and field injection) and @Value with @PropertySource.

## Run
Open the folder in IntelliJ IDEA (it is a Maven project) and run `ug.busbooking.MainApp`, or:
```
mvn compile exec:java
```
